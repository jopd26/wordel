# SHORE Wordle

A tiny Wordle-inspired game where the hidden word is always `SHORE`.

## Run it locally

Open `index.html` directly in a browser, or from the project folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Goal

Guess the five-letter word before you run out of tries. When you solve it, a popup appears with:

> Are you SHORE?
